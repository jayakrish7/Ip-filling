IP Document Generation System Evolution

Stage 1: Structured Feature Risk Classification (ML)

Predicts filing outcomes (Approved, Rejected, Needs_Revision) using tabular ensemble classifiers (Random Forest, Gradient Boosting, SVM).

Stage 2: Unstructured Legal Text & Entity Parsing (NLP)

Classifies clause types via TF-IDF + Logistic Regression and BERT, while extracting patent numbers, filing dates, and statutes using regex heuristics.

Stage 3: Deep Capacity & Time-Series Prosecution Forecasting (DL)

Combines MLP + 1D-CNN tabular classifiers with PyTorch LSTM + Self-Attention models to forecast 24-month prosecution activity timeline.

Stage 4: Edge SLM Fine-Tuning & Local Quantized Deployment (SLM)

Instruction-tunes Flan-T5 / Phi-3 via LoRA, merges weights, and quantizes to GGUF Q4_K_M for offline Ollama paralegal summarization.

Stage 5: RAG Corpus Retrieval & Autonomous Agent Execution (GenAI & Agentic)

Vector precedent retrieval + multi-option drafting coupled with an MCP tool-calling agent that enforces mandatory human review for high-risk filings.
